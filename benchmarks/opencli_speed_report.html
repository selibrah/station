Architecture Comparison: Subprocess Spawning vs. Direct Daemon RPC

❌ OLD: Subprocess CLI Execution (~310ms) HIGH OVERHEAD
1. Python spawns bash subshell subprocess.run(['opencli', ...]) (~80ms)
2. Node.js runtime initializes & loads 169 adapter modules (~140ms)
3. CLI parses arguments & makes ephemeral HTTP connection to daemon (~50ms)
4. Extension evaluates JS and returns output through stdout pipe (~40ms)
⚡ NEW: Direct HTTP RPC Bridge (~11ms) 96% FASTER
1. Reuses open keep-alive socket to http://127.0.0.1:19825/command (<1ms)
2. Header X-OpenCLI: 1 authorizes request instantly (<1ms)
3. Daemon routes payload directly to Chrome Extension WebSocket (~6ms)
4. Returns parsed JSON response directly to Python in memory (~4ms)
