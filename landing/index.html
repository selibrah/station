Technical questions, answered plainly.

Do I need Rust installed to use the macOS app?

No. Station-Studio-v0.4.0-macOS-arm64.dmg embeds both the Swift 6 UI and the compiled station Rust daemon + MCP server inside Station Studio.app/Contents/MacOS/station.

How does Station protect my logged-in Chrome profiles?

Station binds strictly to 127.0.0.1:19826, omits CORS headers so external web pages cannot reach it, blocks non-HTTP schemes, and requires a 256-bit 0600 local token header.

Will background Auto-Jobs interrupt my active window?

Never. Tabs open via CDP Target.createTarget with background: true over a persistent secondary WebSocket pool while you keep coding.

Does Station bypass CAPTCHAs or spam forms?

Never. If a site displays a CAPTCHA or login prompt, Station pauses cleanly and notifies you. Assisted job workflows pre-fill fields and attach your PDF resume, stopping before final submission.
