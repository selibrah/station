04 · TECHNICAL FAQ

Built for speed, privacy & human control.

Do I need Rust or Cargo installed to use Station Studio on macOS?

No. The downloadable Station-Studio-v0.4.0-macOS-arm64.dmg bundles both the native Swift 6 UI and the compiled station Rust daemon + MCP server inside Station Studio.app/Contents/MacOS/station.

How does Station keep my logged-in Chrome sessions safe?

Station listens strictly on loopback (127.0.0.1:19826), disables CORS so external websites cannot talk to it, blocks non-HTTP schemes, and verifies a 256-bit 0600 local token (X-Station-Token) in constant time.

Does Station bypass CAPTCHAs or auto-spam job applications?

Never. Station respects human-in-the-loop boundaries: if a CAPTCHA or login gate appears, it stops cleanly and notifies you. Assisted application workflows pre-fill fields and attach your resume, pausing before the final Submit click.
